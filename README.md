# YouTube Live Helper

YouTubeの視聴を快適にする便利機能を詰め合わせたChrome拡張機能です。ライブ配信向けの機能が中心ですが、画質の自動設定は通常動画・Shortsでも動作します。

主な機能：

- **ライブヘッドへの自動シーク** — 配信ページを開くと自動で最新位置（ライブヘッド）までシーク
- **チャットの自動全表示** — チャット欄を「トップチャット」から「チャット（すべて表示）」へ自動切り替え
- **固定メッセージの自動非表示** — 配信主がピン留めしたメッセージ（バナー）を自分の画面から自動で非表示
- **アンケートの自動非表示** — 配信主がチャットで実施するアンケートを自分の画面から自動で非表示
- **ライブ中チャンネルの並べ替え** — 左サイドバーの「登録チャンネル」で、配信中のチャンネルを一覧の先頭へ自動で移動
- **登録チャンネルの自動展開** — 左サイドバーの「登録チャンネル」を常に展開した状態で表示
- **画質の自動設定** — 指定した画質、または利用可能な最高画質へ自動で切り替え（通常動画・Shortsを含むYouTube全体）

Chrome Web Storeには公開していないため、手動でインストールして使用してください。

---

## インストール

```bash
git clone git@github.com:huro3h/yt-live-helper.git
```

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. クローンしたフォルダを選択

## 使い方

インストールするだけで動作します。ライブ配信中の動画ページ（`youtube.com/watch?v=...` または `youtube.com/live/...`）にアクセスすると、自動で配信の最新位置までシークし、チャット欄を「すべて表示」に切り替え、固定メッセージやアンケートを非表示にします。画質の自動設定は、ライブ配信に限らずYouTube上の動画再生ページとShortsで動作します。

Chromeツールバーの YouTube Live Helper アイコンをクリックすると、以下の設定を切り替えられます。

**ライブ配信**

| 設定 | 説明 |
|------|------|
| 常に最新位置から再生 | OFFにすると自動シークを無効化できます（追っかけ再生をしたい場合など） |
| チャットを常に全表示 | OFFにするとチャットの自動切り替えを無効化できます（トップチャットのままにしたい場合など） |
| 固定メッセージを自動で非表示 | OFFにすると固定メッセージ（ピン留めバナー）を通常どおり表示します |
| アンケートを自動で非表示 | OFFにするとアンケートを通常どおり表示します |

**サイドバー（登録チャンネル）**

| 設定 | 説明 |
|------|------|
| ライブ中のチャンネルを上に表示 | OFFにすると並べ替えをやめ、YouTube本来の並び順に戻します |
| 登録チャンネルを常に展開 | ONにすると「もっと見る」を毎回押さなくても全チャンネルが表示されます |

**画質（通常動画・Shorts含む）**

| 設定 | 説明 |
|------|------|
| 画質を自動設定 | OFFにすると画質に一切干渉しません（YouTubeの自動画質のまま） |
| 常に最高画質を使う | ONにすると、その動画で利用可能な最高画質を使います（デフォルト画質より優先） |
| デフォルト画質 | 使用する画質（既定: 1080p）。動画側の最高画質がこれを下回る場合は、その中の最高画質になります |

## 仕組み

### ライブヘッドへの自動シーク（`live-bridge.js` + `live-inject.js`）

プレーヤーのAPI（`getProgressState()` / `seekToLiveHead()`）はページ側（MAIN world）からしか呼べず、`chrome.storage` は拡張機能側（ISOLATED world）からしか読めないため、2つのスクリプトに分かれています。

1. `live-bridge.js`（ISOLATED world）が設定（ON/OFF）を読み、`CustomEvent` で `live-inject.js` へ渡す
2. `live-inject.js`（MAIN world）が、設定を受け取ってから動画ページ（`/watch` または `/live/`）へのアクセス・SPA遷移（`yt-navigate-finish`）を検知
3. プレーヤーがライブ表示になり（`.ytp-time-display` に `.ytp-live` が付く）、かつ実際に再生が始まる（`getPlayerState()` が再生中）まで待機（配信中でない動画・広告の再生中は何もしない）
   - `.ytp-live-badge` 要素自体は通常動画のプレーヤーにも存在する（CSSで非表示になっているだけ）ため、要素の有無ではライブ判定に使えません
4. `seekToLiveHead()` で最新位置へシークし、`getProgressState().isAtLiveHead` で到達を確認。到達するまで最大30秒リトライする

### チャットの自動全表示・固定メッセージの非表示（`chat.js`）

`chat.js` がチャットの iframe（`youtube.com/live_chat`）に注入され、2つの処理を行います。

**チャットの自動全表示**

1. 表示切り替えドロップダウン（`#view-selector`）が描画されるまで待機
2. メニューを開き、「チャット（すべて表示）」の項目を選択（既に全表示なら何もしない）

**固定メッセージの非表示**

1. iframe に `<style>` を1つ注入し、固定メッセージのバナーだけを `display:none` にする（`yt-live-chat-banner-renderer:has(yt-live-chat-text-message-renderer)`）
2. YouTubeの「固定を解除」は押さないため、自分の画面から消えるだけで**他の視聴者には一切影響しません**（モデレーター/オーナーであっても安全）。再ピン留めされたメッセージにも自動で効きます

**アンケートの非表示**

1. iframe に `<style>` を注入し、アンケート（`yt-live-chat-poll-renderer`）を含む要素を `display:none` にする
2. アンケートの格納先はチャット表示モードで変わるため、両方の格納先を対象にする
   - トップチャット時：最下部の `#action-panel` 内
   - すべて表示時：上部のバナーマネージャ内へ移動（YouTubeはこのモードでアンケートを正常描画せず、崩れた状態で残す）
3. 固定メッセージ同様、自分の画面から消えるだけで他の視聴者には影響しません

---

### サイドバーの登録チャンネルの並べ替え（`guide.js`）

1. 左サイドバーの「登録チャンネル」セクションを、見出しのリンク先（`/feed/subscriptions`）で特定する（見出しの文言は言語設定で変わるため使わない）
2. 各エントリがライブ配信中かどうかは、赤いライブアイコン（`.guide-entry-badge` 内の `svg`）が描画されているかで判定する
   - バッジ要素自体は全エントリに存在しCSSで非表示になっているだけなので、要素の有無では判定できません（未視聴を示す青い丸とも別物です）
3. 「もっと見る」の中身は展開するまでDOMに生成されないため、一度だけ展開して実体化させる
   - 「登録チャンネルを常に展開」がOFFのときは、一時的なCSSで見た目を固定したまま展開→折りたたみを行うため、サイドバーがちらつきません
   - 並べ替えてから折りたたむとYouTube側の再描画で元に戻ってしまうため、必ず折りたたんでから移動します
4. ライブ配信中のエントリを（YouTube本来の並び順を保ったまま）一覧の先頭へ移動する。配信が終わったチャンネルは元の位置へ戻す
5. 配信の開始・終了やYouTube側の再描画には MutationObserver で追従する

---

### 画質の自動設定（`quality-bridge.js` / `quality-inject.js`）

もともと独立した拡張機能（`yt-auto-quality-lite`）だったものを統合した機能です。YouTubeプレーヤーが内部的に持つ非公開メソッド（`getAvailableQualityLevels` / `setPlaybackQualityRange`）を直接呼び出して画質を切り替えます。

1. `quality-bridge.js` がISOLATED worldで動作し、`chrome.storage.local` から設定を読み取ってCustomEventで橋渡しする
2. `quality-inject.js` がMAIN worldに注入され、プレーヤー要素（`.html5-video-player`）の非公開メソッドを呼び出して画質を適用する
   - `chrome.storage` はISOLATED worldからしか触れず、プレーヤーの非公開メソッドはMAIN worldからしか呼べないため、2つのスクリプトに分かれています
3. SPA遷移（`yt-navigate-finish`）と1.5秒間隔のフォールバックタイマーで、動画の切り替えや画質リストの準備待ちにも追従する
4. 対応範囲は `www.youtube.com` の動画再生ページとShorts（埋め込みプレーヤー・YouTube Musicは対象外）

非公開APIに依存しているため、YouTube側の実装変更で動作しなくなる可能性があります。

## ファイル構成

```
yt-live-helper/
├── manifest.json     # 拡張機能の設定（Manifest V3）
├── popup.html        # ポップアップUI（設定トグルのみ）
├── popup.js          # ポップアップのロジック
├── live-bridge.js    # ライブヘッドへの自動シークの設定受け渡し（ISOLATED world）
├── live-inject.js    # ライブヘッドへの自動シークの実行（MAIN world）
├── chat.js           # チャットiframe内スクリプト（チャットの自動全表示・固定メッセージ/アンケートの非表示）
├── guide.js          # 左サイドバーの登録チャンネルの並べ替え・自動展開
├── quality-bridge.js # 画質設定の受け渡し（ISOLATED world）
├── quality-inject.js # 画質の適用（MAIN world）
├── icons/
│   ├── icon16.png
│   ├── icon48.png
│   └── icon128.png
└── README.md
```

## トラブルシューティング
###### (この拡張機能は永遠にWIPです。作者が利用中正常動作しないことに気づいて気力があったら都度修正します)

#### **自動で最新位置に移動しない**
YouTubeのプレーヤーのDOM構造が変更された場合、シーク処理が機能しなくなることがあります。その場合はお手数ですが手動でシークバーを操作してください。

#### **チャットが自動で全表示に切り替わらない**
YouTubeのチャットUI（表示切り替えドロップダウン）のDOM構造が変更された場合、切り替え処理が機能しなくなることがあります。その場合はお手数ですが手動で「チャット」に切り替えてください。

#### **固定メッセージが消えない**
YouTubeのチャットバナーのDOM構造が変更された場合、非表示用のCSSが効かなくなることがあります。その場合はお手数ですが手動で固定メッセージを折りたたむ／解除してください。

#### **アンケートが消えない**
YouTubeのアンケートのDOM構造が変更された場合、非表示用のCSSが効かなくなることがあります。その場合はお手数ですが手動で対応してください。

#### **ライブ中のチャンネルが上に来ない／登録チャンネルが展開されない**
YouTubeのサイドバー（ガイド）のDOM構造が変更された場合、並べ替えや展開が機能しなくなることがあります。その場合はお手数ですが手動で「もっと見る」を押してください。

#### **画質が指定どおりにならない**
YouTubeプレーヤーの非公開APIに依存しているため、YouTube側の実装変更で機能しなくなることがあります。また、動画側がその画質で配信されていない場合は、利用可能な最高画質までしか上がりません。

#### **Windows、Linuxで動きますか？、BraveやEdgeでも動きますか？**
作者の開発環境がMac、Chromeのみの為、他環境は動作未検証です。動かない場合は自力で何とかしてもらうか、このリポジトリごとコーディングエージェントに丸投げして聞いて下さい
